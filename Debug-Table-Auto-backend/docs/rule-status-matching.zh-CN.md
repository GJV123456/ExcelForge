# 设备类型与子类型规则匹配说明

规则目录只使用父设备类型和设备子类型决定操作步骤与输出结果。`equipmentStatus` 不属于规则目录，不保存、不展示、不参与规则匹配；它只可作为 Excel 原始数据的输入字段保留。

```text
equipmentType + equipmentSubtype
             ↓
唯一测试规则
             ↓
操作步骤 + 输出结果 + 责任专业
```

例如：

```json
{
  "equipmentType": "防火阀",
  "equipmentSubtype": "电动防火阀"
}
```

匹配该父类型下“电动防火阀”子类型的规则：

```text
操作步骤：现场动作专用排烟电动阀关闭
输出结果：动作状态对应的现场、FAS主机、FAS图文工作站、综合监控结果
```

规则选择器表只保存父类型和子类型：

```text
test_content_selectors
```

其他设备也采用相同的父类型/子类型匹配原则，包括：

- 排烟机
- 加压送风机
- 监视模块下的吸气式主机、感温电缆、感温光纤、AFC、EPS、垂直电梯、防火卷帘、400V切非、消防泵、门禁释放等
- 控制模块下的 AFC、EPS、PA、声光报警器、主机手自动/人工确认等
